# Source work only

Do not open, launch, control, refresh or build with Unity, invoke its compilers, or
run adb unless the user explicitly authorizes that action. Work on source and static
checks. Preserve unrelated changes. State when compilation or gameplay is unverified.

This is an independent game, not a worktree of terra-game. Keep one player, fists,
jetpack, all player controls, fixed full quality, and one offline 2 km × 2 km Helsinki
map (City of Helsinki 3D reality mesh 2017, moved from terra-game). No lobby, settings
screens, guns or remote map streaming. Copy only dependencies actually needed.
RawMaps is source data; keep it outside Unity Assets.
